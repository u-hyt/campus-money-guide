LEARNING NOTE 04 / NISA

NISAは金融商品ではなく税制上の制度

NISA口座では対象商品の投資利益が制度の範囲内で非課税になりますが、商品の価格変動や元本割れリスクは残ります。2026年時点の制度では、原則として日本国内に住む18歳以上が対象です。2027年以降の制度変更も案内されているため、条件や開始時期は申込時点の金融庁・金融機関の情報で確認してください。

確認しておきたいポイント

  • 商品や制度の最新条件を公式情報で確認する
  • 手数料、値動き、元本割れの可能性を理解する
  • 疑問が残る時は申込みや注文を急がない
