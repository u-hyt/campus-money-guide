LEARNING NOTE 01 / お金の基本

投資の前に考える、生活費と予備資金

まず毎月の収支と、近いうちに使う予定のお金を整理します。家賃、学費、食費、交通費など生活に必要な支出は、価格が変動する投資資金と分けて考えます。投資は余裕資金で行い、値下がりしても必要な支払いに影響しない金額かを考えてください。

確認しておきたいポイント

  • 商品や制度の最新条件を公式情報で確認する
  • 手数料、値動き、元本割れの可能性を理解する
  • 疑問が残る時は申込みや注文を急がない
