LEARNING NOTE 02 / 投資の基本

リスクとリターン、元本割れを知る

投資でいうリスクは、価格や結果の振れ幅を指します。大きく上がる可能性がある商品は、下がる幅も大きくなることがあります。元本割れとは、売却時の受取額が投資額を下回ることです。過去の成績は将来の利益を保証しません。仕組みを理解できない商品は、判断を急がず公式資料を読みましょう。

確認しておきたいポイント

  • 商品や制度の最新条件を公式情報で確認する
  • 手数料、値動き、元本割れの可能性を理解する
  • 疑問が残る時は申込みや注文を急がない
