LEARNING NOTE 09 / 大学生の家計

投資を家計に組み込む前の整理

アルバイト代、仕送り、奨学金などの入金と、家賃・食費・学費などの支出を書き出します。奨学金は返済の有無や契約条件を確認しましょう。数年以内に使う予定のお金と投資資金を分け、周囲の人の金額をまねせず、自分の収支に合わせて考えます。投資を始めない選択もできます。

確認しておきたいポイント

  • 商品や制度の最新条件を公式情報で確認する
  • 手数料、値動き、元本割れの可能性を理解する
  • 疑問が残る時は申込みや注文を急がない
