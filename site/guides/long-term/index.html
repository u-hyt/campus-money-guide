LEARNING NOTE 03 / 投資の基本

長期・積立・分散の考え方

長期は時間をかけて続ける考え方、積立は購入時期を分ける方法、分散は投資先の偏りを抑える工夫です。どれも損失をなくす方法ではなく、利益を保証しません。近く使う予定のお金を投資に回さず、家計や予定が変わったときには金額や計画を見直します。

確認しておきたいポイント

  • 商品や制度の最新条件を公式情報で確認する
  • 手数料、値動き、元本割れの可能性を理解する
  • 疑問が残る時は申込みや注文を急がない
